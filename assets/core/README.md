# Core console presentation

The console adds lightweight procedural presentation geometry around the registered ownship visual
proxy: naval-gray deck structure, sensor mast, radome, EO/IR sensor cue, mission-bay deck, and
navigation lights. This geometry is fictional and original to the console. It is not a model of a
specific Singapore or defence platform. Simple deck and CIWS-like silhouettes are static and
non-functional: they have no controls, target/contact linkage, tracking, engagement logic, firing
animation, or performance parameters. All procedural geometry has no collision, fire-control,
actuation, or assurance role.

The scene uses a Singapore Strait-inspired harbour treatment without geographic coordinates or a
claim that the source scenario occurred there. Public snapshot hulls and NED state remain
authoritative. Ocean waves and all procedural fittings are visual effects only.

Third-party maritime models and their provenance remain in `assets/maritime/registry.json` and the
visible console attribution. A09 owns those registered assets. A10 owns marine-environment rendering
and physical-effects integration contracts.
